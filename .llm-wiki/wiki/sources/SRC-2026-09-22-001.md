# Kraken 2, KrakenUniq and Bracken indexes
> _Original: [https://benlangmead.github.io/aws-indexes/k2](https://benlangmead.github.io/aws-indexes/k2)_

## Summary

The Langmead Lab index page publishes versioned Kraken 2 and Bracken database packages. Each package includes the Kraken 2 index plus Bracken distributions for 50, 75, 100, 150, 200, 250, and 300-mers. Capped collections such as Standard-8 use Kraken2's `--max-db-size` to reduce the index size at some sensitivity and accuracy cost.

The June 26, 2026 Standard-8 package contains the standard RefSeq archaea, bacteria, viral, plasmid, human, and UniVec_Core collections. Its archive is listed as 5.5 GB and its unpacked index as 7.5 GB. The page provides the archive URL, inspect output, library report, and MD5 file. It also documents that the archive contents include `inspect.txt`, taxonomy and library metadata, and checksums.

## Key Takeaways

- Use the upstream publication date, `2026-06-26`, as the immutable asset version rather than the CAPE upload date.
- Identify the package as `Standard-8`, and preserve the source archive, inspect URL, library URL, MD5 URL, archive size, index size, and collection description in a manifest.
- The asset can be published to the shared CAPE meta-assets bucket through an external publisher without keeping the 5.5 GB archive or 7.5 GB unpacked database in the repository.
